# Sintelo Core — Ownership and Custody

## 1. Ownership

Sintelo Core es propiedad exclusiva de Sintelo.

Sintelo Core constituye un activo propietario de la firma y forma parte de su infraestructura técnica institucional permanente.

Todos los derechos sobre el código, arquitectura, modelos, documentación y outputs generados dentro de este repositorio pertenecen a Sintelo.

Este repositorio está alojado bajo la organización institucional oficial de Sintelo en GitHub:

sintelo-ai

Ningún individuo posee Sintelo Core.

---

## 2. Custody

El acceso al repositorio es otorgado a individuos específicos con el propósito de desarrollar, mantener y evolucionar el sistema bajo la dirección institucional de Sintelo.

El acceso constituye custodia operativa, no propiedad.

La custodia puede ser modificada, limitada o revocada en cualquier momento por Sintelo.

---

## 3. Contributions

Todas las contribuciones realizadas dentro de este repositorio como parte de actividades relacionadas con Sintelo se consideran trabajo realizado para Sintelo y pasan a formar parte del activo institucional.

Esto incluye:

— código  
— documentación  
— arquitectura  
— configuraciones  
— artefactos derivados  

No se reconoce propiedad individual sobre contribuciones realizadas dentro de este repositorio.

---

## 4. Control

El control institucional del repositorio reside en Sintelo.

Sintelo mantiene la autoridad final sobre:

— acceso al repositorio  
— dirección técnica  
— decisiones de arquitectura  
— evolución del sistema  

---

## 5. Continuity Principle

Sintelo Core está diseñado para ser un sistema institucional continuo, independiente de cualquier individuo específico.

La arquitectura, documentación y gobernanza están estructuradas para asegurar continuidad operativa independientemente de cambios en el equipo técnico.

---

## 6. Effective Date

Este documento entra en vigor a partir de su incorporación al repositorio oficial de Sintelo Core.

---

## 7. Summary

Sintelo Core es un activo institucional propiedad de Sintelo.

El acceso constituye custodia, no propiedad.
