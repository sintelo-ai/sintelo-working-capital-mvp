# Sintelo Core — Data Policy

## Principle
Este repositorio no debe contener datos sensibles o identificables de clientes.

## Allowed
— datos sintéticos o anonimizados  
— artefactos pequeños (“golden outputs”) para pruebas reproducibles  
— fixtures mínimos para validación

## Not Allowed
— dumps completos de ERP  
— datasets con información identificable  
— archivos pesados sin necesidad operativa

## Handling
Datos reales deberán gestionarse fuera del repositorio bajo controles de acceso definidos por Sintelo.
