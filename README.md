# Sintelo Core

## Descripción

Sintelo Core es el motor propietario de análisis financiero y creación de valor de Sintelo.

Constituye la infraestructura técnica central utilizada para transformar datos operativos y contables provenientes de sistemas ERP en información institucional utilizada para:

— evaluar el uso del capital invertido
— identificar capital operativo inmovilizado
— cuantificar oportunidades de liberación de capital
— soportar procesos de decisión financiera y operativa

Sintelo Core es un activo propietario de Sintelo y forma parte de su infraestructura institucional permanente.


## Propósito institucional

El propósito de Sintelo Core es operar como el sistema central de procesamiento y análisis financiero de la firma, permitiendo:

— ingestión estructurada de datos multi-ERP
— normalización financiera bajo un modelo institucional único
— cálculo de métricas financieras críticas (capital de trabajo, capital invertido, retornos operativos)
— generación de outputs analíticos utilizados en procesos de creación de valor

El sistema está diseñado para operar de forma automatizada, escalable y auditable.


## Alcance funcional

Sintelo Core procesa datos operativos a nivel transaccional y genera como outputs principales:

— tablas analíticas institucionales
— indicadores financieros estructurados
— simulaciones de escenarios operativos
— datasets utilizados en procesos de análisis y toma de decisión

Sintelo Core no es un sistema de visualización.
Es un sistema de procesamiento y generación de inteligencia financiera.


## Arquitectura

Sintelo Core forma parte de una arquitectura institucional compuesta por múltiples capas:

— capa de ingestión de datos
— capa de procesamiento
— capa de almacenamiento estructurado
— capa de análisis propietario
— capa de consumo por aplicaciones y herramientas analíticas

La arquitectura completa se documenta en el directorio /architecture.
